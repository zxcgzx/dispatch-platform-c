# 设计与口径说明

## 主线

自然语言指令 → 解析与层级判定（L1–L4）→ 模型规格 M = {ω, Δπ, s, R} → 公式与代码确认 → 五层校验 → 求解 → 结果与地图 → 指标与风险 → 协商调整出新版本。建模完成后也可以先去风险评估与协商，再决定是否求解。

## 架构

- **规格是唯一中间产物**：`backend/app/spec/schema.py`（Pydantic v2）导出 JSON Schema，前端用 `json2ts` 生成类型。
- **层级由程序判定**：有推断项即“推断”，有结构修改即“改结构”，四种组合对应 L1–L4；用户可手动改选并留痕，统计按程序判级。
- **三种建模引擎**：演示规则引擎（离线）、OpenAI 兼容接口（本地小模型，连不上自动回落）、外部动态建模服务（HTTP，`/parse` 与 `/check`）。
- **去幻觉**：原文依据必须是指令的子串；对象必须存在，找不到时保留原编号交给校验，不替换；独立抽取指令里的对象与要求，检查遗漏。
- **代码页的代码就是试构建执行的代码**：`modeling/codegen.py` 生成 `model.py`，`modeling/trial.py` 在子进程里执行同一份文件（T = 1，跳过 N−1）。
- **状态唯一来源**：`backend/app/features.py` 输出 `/api/features`，前端启动时读取，后端未起时用 `features.fallback.json`。
- **离线运行**：字体、图表库、地图底图全部随包打包。

## 数据口径

| 项 | 口径 |
| --- | --- |
| 规模 | 905 母线、237 机组、1000 支路，基准容量 100 MVA |
| 断面与时段 | 一个断面对应一个时段；多个断面按时刻排成连续窗口（最多 16 个，间隔 15 分钟） |
| 编号 | 母线 B{BUS_I}；支路按行号 L{n}（有 67 组并联支路）；机组按行号 G{n} |
| 断面时刻 | 取 Dict Info 的 time，与文件名时间戳不一致时在数据质量里提示 |
| **RATE_A** | 额定电流（A）。热稳限额 S = √3 · kV · I / 1000（MVA），kV 取首端母线电压；0 表示不限。负载率、热稳约束、N−1 筛查统一用折算后的 MVA |
| 孤岛型支路 | 在运、是桥、且没有并联在运支路：775 条；网状部分 225 条（35kV 118、220kV 63、110kV 33、500kV 11） |
| 可开断变量数（16 时段） | 全部支路 16000；网状部分 3600；网状且 ≥110kV 1712；加机组启停（237 × 16）后达到万级 |
| 数据质量 | 如实展示、不修正：231 个母线 VM > VMAX，101 台机组 PG 越界，5 条支路 RATE_A = 0，248 个母线 PD < 0，母线 176 有两台约 ±2000 MW 的等值机组 |
| 新能源 | RENEWABLE 列全为 0，没有新能源机组标注，新能源消纳率与新能源消纳目标暂不起作用 |
| 成本 | 断面里没有发电成本；基础目标是偏离当前方式最小，经济性目标需要用户给出单价 |

## 建模

- **基础模型 ω**：多时段 AC-OTS，N−1 默认开启。B1 有功平衡、B2 无功平衡、B3 支路潮流与开断、B4 热稳、B5 电压、B6 机组、B7 不可开断支路、B8 平衡节点、B9 N−1（抽象块，展开形式由求解链定义）。
- **优化类型可切换**：AC-OTS / AC-OPF（固定拓扑）；机组出力调整、机组启停可叠加。
- **结构算子库**（`config/operators.yaml`）：固定拓扑、每时段开关次数上限、开关总次数上限、断面限额、开关惩罚、网损、电压偏差、机组出力调整（可限爬坡）、机组启停（0-1，限启停总次数）、经济性目标、可靠性目标、新能源消纳目标。
- **目标函数类别**：偏离当前方式（基础）、开关操作、网损、电压偏差、经济性、可靠性、新能源消纳。
- **规模估算**：变量数、0-1 变量数、约束数按模板逐块计数，三种可开断集合口径并列，机组启停变量单列。
- **推断项**：幅度必须由用户确认；规程默认值未配置时“按规程默认值”置灰。
- **试构建**：子进程执行同一份代码，`custom_code` 先静态检查；不是完整沙箱，生产环境应加容器与资源限制。

## 校验

五层：规格合法、结构一致、数据检查、可执行、语义回译。错误阻止求解，警告需确认。

**无解诊断**：求解不可行时，对限额修改、断面限额、开关次数、机组范围、停运等约束逐项放开重新求解，放开后变可行的就是冲突来源；单项放开都不行时，累加放开直到可行，给出需要同时放宽的一组。

## 求解

- **builtin**（默认）：HiGHS（`scipy.optimize.milp`）求解直流近似 OTS。目标是偏离当前出力最小加开关惩罚；机组启停、爬坡、经济性目标均可叠加。直流模型不输出电压，也没有网损，网损与电压偏差目标在内置求解器里不起作用。
- **等值注入**：断面总出力比总负荷多约 679 MW（网损约 105 MW，其余为等值注入），按断面固定计入节点平衡，使断面本身是可行点。
- **mock**：不生成任何方案或曲线。
- **import**：上传结果 JSON，按 `result_schema.json` 校验。
- **external**：执行 `SOLVER_CMD`，可接 IPOPT 热启动链路或商业求解器（COPT / Gurobi）。
- 不做任何求解加速、调参、热启动。

## 指标与风险

- 负载率：max(√(PF²+QF²), √(PT²+QT²)) / 热稳限额；≥80% 计重载，≥100% 计越限。
- 电压偏移：|VM − 1|，统计越出 [VMIN, VMAX] 的母线。
- **N−1 通过率（直流筛查）**：PTDF / LODF 筛查，非交流 N−1 校核；LODF 用逐事故重解直流潮流交叉验证。事故前就已超限的支路单列，不算事故造成的越限。孤岛型事故不进 LODF，单列。
- 静态电压稳定裕度需要连续潮流，新能源消纳率需要标注新能源机组，二者待开发。
- 本地风险规则：ρ ≥ 100% 或 N−1 不通过为“高”；ρ ≥ 80% 或电压越限为“中”；其余为“低”。配置 `RISK_ENDPOINT` 后改调课题 3 接口。
- **协商**：按风险原因生成待确认的调整建议，数值一律留空由用户填写，生成新版本回到规格确认。
- **Reward**：风险等级折算奖励的接口预留；页内给出 CMDP 的状态、动作、奖励、安全代价的结构化描述。

## 聚合与分解

问题类型识别、节点聚合（35kV 及以下叶子并入上级）、时段聚合、按县域分区与联络线统计。多智能体协同求解待开发。

## 测点转换

每个母线对应一个母线测点；每条线路两端各插入一个虚拟开关，线路参数放在两个开关之间；变压器（变比 ≠ 0）中间是变压器测点；发电机与负荷不建独立测点，信息挂在边界开关上。输出静态与动态两组表。逆向恢复需要映射表（61 个母线挂多台机组，67 组并联支路）。方案回写为两端虚拟开关动作。

## 地图

底图为大理白族自治州行政区划（12 个县市），默认用纯 SVG 绘制，可切换 ECharts。数据里没有变电站经纬度，节点位置是按拓扑分区落在各县范围内的示意位置。

## 交流基准

16 时段完整非线性交流 OTS（MATLAB + MATPOWER 8 MIPS）的计算结果只读展示：240 次交流 OPF、16 次静态 N−1，全程开断 L151。由 `scripts/import_matlab_benchmark.py` 生成摘要 JSON，不拷贝原始大文件。MATLAB 算例对断面做了机组合并、负 PD 置零等处理，数值与内置直流求解不能逐项对比。
